# Character reference roles

- `komichi-fullbody.png`: primary full-body proportions, outfit, scarf, skirt, stockings, and shoes.
- `komichi-face-smile.png`: primary face, hair, hair clips, eye color, vertically stacked viewer-right tear moles, traffic-light pendant, and relaxed expression.
- `komichi-face-surprised.png`: secondary face, the same two-mole placement, traffic-light pendant, and open-mouth expression reference.
- `fanwork-policy.png`: provenance record for the stated fanwork guidance; never pass this file to the image generator.

The three character images are identity references only. They are not cut out and pasted into the street photograph. Every output must generate a new pose and composition while preserving the recognizable character design.

The neck design has two valid variants: the red scarf from the full-body reference or the traffic-light pendant from the face references. Select exactly one per generated image, randomly and independently of shot scale; never combine both.
